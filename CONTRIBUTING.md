# Contributing

1. Fork the repository and create a branch: `git checkout -b my-change`
2. `npm install`, then `npm run dev` and test on http://localhost:8787 in both languages and on a phone width
3. `npm run check`
4. Open a pull request. One change per pull request, with a screenshot if it changes the look

Rules:

- Anything personal (names, links, accounts) belongs in `site.config.js`, never in the code
- A new feature needs an on/off switch in `sections`
- By sending a pull request you agree to the contribution terms in [LICENSE-PERMISSIONS.md](LICENSE-PERMISSIONS.md)
- No tokens, keys or real donor names in code, issues or screenshots
- Found a security problem? See [SECURITY.md](SECURITY.md) instead of opening an issue
